# Python Notes and Questions:

## What is Python?
Python is a high readability coding language that makes coding really easily and accesible. 
## Why is Python popular?
Python has a high level of readability and is extremely easy for humans to read. It also takes away the necessity on declaring strings. It's also what a good portion of the internet uses for coding now and is becoming increasingly more popular simply because of it's trendy simplicity and easy-to-learn interface.
## Variables:
I mean, it's self explanatory. You can stores strings, integers, bools (true or false), and floats.
## Data Types: 
The main ones I already knew about and learned about:
Integer = Non-decimal whole-numbers
String = A finite sequence of characters used to represent text
Boolean = Basically True or False, imagine a light switch
Float = A float is like an integer but represents REAL numbers, adds that fractional component and makes them more useful for scientific data and storing more numbers. 
## Printing:
Printing is when you show the user text results.
## Input: 
Pretty self-explanatory, input is what the user puts into the code to give it values and produce the output. According to CS50, all code is basically: 
        INPUT -----> ( O U R     C O D E ) -----> OUTPUT
## Comments:
Comments are little text pieces that don't affect the actual code and it can be put anywhere, and is used for programmers to make notes to themselves or communicate other information to other programmers. 
## Basic Math:
Python has built in operators for mathematics, making it extremely simple to calculate and build mathematical systems in your code. Instead of making code for squaring, Python provides a function like that.
## Common Mistakes:
Python has a very simple coding system for it's users which also means there are more problems that can arrise if users do something wrong. For example, Python is case sensitive so you have to be careful what you capitalize. Another example is confusing "is" with "=" which do different things.
