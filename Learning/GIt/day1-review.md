# Questions

##### 1. What Problem does Git solve?
Git solves a multitude of problems, but the main thing it does is create a system for developers to easily collaborate on code and codebases in and open-ended system that way developers no longer have to share thumb-drives or files and deal with difference's in computer systems and operating systems, instead having one consistent platform for it all to be done.

##### 2. What is a repository?
A repository is simply the collection of files that act as a library of code and history of changes (commits, adds, and such).

##### 3. What is a commit?
A commit is when a developer actually moves something from the staging area into the working repo. It's the second to last phase for a feature to go to before pushing into the actual remote code. 

##### 4. Why do branches exist?
Branches exist for the devs and coding partners to make bug fixing and editing code available and simple without removing the original code's functionality or breaking things. It's like being able to model in SolidWorks with the sketching feature on an already built feature before extruding it or committing it to the 3D space. 

##### 5. What is the difference between Git and GitHub?
Git is the service itself, being the working, local repo on a computer, while GitHub is an online cloud-based repo service for uploading code and backing up your projects as well as sharing and doing another important things that can't just be done with a single offline system.
