# About Me

## Description

A simple Python program created to practice the fundamentals of programming while introducing myself through code.

The program collects and displays basic information about me, including personal interests, education, and other details. It was one of my early Python projects and helped me become more comfortable with writing functions, working with variables, and organizing a program.

## Features

* Displays personal information
* Uses functions to organize different sections of the program
* Uses variables to store information
* Demonstrates formatted output
* Demonstrates basic Python program structure

## What I Learned

This project helped me practice:

* Variables
* Strings
* Functions
* User input
* `print()`
* Formatted strings (f-strings)
* Basic program organization
* Returning values from functions
